# progress-timeline

Claude Code（デスクトップアプリの Code タブ、ターミナル）の右側のペインに、プロジェクトの進捗を表示する MOD です。

## インストール

ターミナルの Claude Code のプロンプトで:

```
/plugin install progress-timeline --marketplace uta-a/claude-progress-timeline
```

`Add marketplace?` には `y` で答え、スコープを選びます。シェルからは次のとおりです。

```bash
claude plugin install progress-timeline --marketplace uta-a/claude-progress-timeline
```

デスクトップアプリでは、プロンプト欄の横の + から Plugins を開き、Add marketplace に `uta-a/claude-progress-timeline` を入れてから Add plugin で追加します。

## 表示するもの

ペインは 2 つのタブに分かれています（ペインにフォーカスがあるときは 1 / 2 キーで切り替え）。

- 1: タスクツリー
  - 見出しはそのリストを作ったときの依頼文。リストが複数あるときは、その下の ‹ › で切り替え
  - 進捗カード: 割合、状態と経過時間、プログレスバー（完了数）、進行中のタスク、「続行を依頼」ボタン
  - タスクの行: 状態の印（● 完了 / ◐ 進行中 / ○ 未着手）と見出し。進行中は太め、完了は灰色の打ち消し線で表示。グループには完了数とプログレスバーを出し、押すと折りたためる
  - 最近の動き: 閉じているときは最新 1 件、開くと直近 5 件
- 2: レポート: タイムライン全体を日付ごとに表示。印は依頼 ›、計画 ◇、開始 ◐、完了 ●、編集 ·、コミットと push ◆

デスクトップアプリでペインを最小化（widget）すると、プログレスバーと進行中のタスクだけを表示します。

ターミナルでは枠を使わず、割合・バー・件数を 1 行、進行中のタスクと経過時間・続行ボタンを 1 行にまとめます。幅が狭いときはタブ名と経過時間を省きます。

- フルスクリーン表示（設定の `"tui": "fullscreen"`）で端末の幅が 110 列以上あるときは、会話の右側に並べて表示します
- それ以外ではプロンプトの上に出ます。高さはタスクの数に合わせて求めます（最大 24 行）

## データの取り方

会話に積まれる行（`session.append`）を読むだけで、行の中身は変更しません。次のツール呼び出しからタスクを拾います。

- `mcp__ccd_turn__update_plan`（デスクトップアプリのタスクリスト。`items` / `advance` / `done` / `start` を解釈する）
- `mcp__todo-tree__set_todos`（`group` をツリーの親にする）
- `TodoWrite`
- `TaskCreate` / `TaskUpdate`

サブエージェントの行は対象外です。

## 保存

記録は作業ディレクトリごとに `$.store` に保存するので、同じプロジェクトで新しいセッションを開いても続きから表示されます。タイムラインは直近 300 件まで保持します。

同じプロジェクトを複数のセッションで同時に開いた場合、書き込みのたびに保存済みの記録を土台にするので、互いの記録は消えません。ただし相手側のペインは、そのセッションで次に記録が増えるまで更新されません。

## コマンド

- `/progress`: ペインを開き、最新のタスクリストの割合・完了数・状態・経過時間、プログレスバー、タスクツリーを会話に表示する
- `/progress clear`: このプロジェクトの記録を消す
